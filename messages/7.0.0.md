# Php Form Builder 7.0.0

- update for Php Form Builder v7.0
- new completions: `setLayout`, `getOptions`, `getCode`, `getIncludes`, `getJsCode`, `startDiv`, `endDiv`, `addAltcha`

- updated plugin names list for `addPlugin` (36 plugins)
- updated `setOptions` defaults for Bootstrap 5
- fixed `addRecaptchaV3` completion
- README updated
